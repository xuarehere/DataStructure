📋 题目描述 🔗 LeetCode 原题链接 ↗

给你一个链表，删除链表的倒数第 n 个结点，并且返回链表的头结点。

🧪 官方三大示例（注意：官方特意塞进了删中间、删唯一头、删尾 3 种拓扑！）
示例 1（标准中段删除） 输入: head = [1,2,3,4,5], n = 2 ➔ 输出: [1,2,3,5]
示例 2（极端边界：单节点删头归零） n == sz
输入：head = [1], n = 1
输出：[]（返回 None）
示例 3（边界：双节点删尾） n == 1
输入：head = [1, 2], n = 1
输出：[1]
🔎 提示与约束条件（INTJ 情报解码）
  • • 1 <= sz <= 30 ➔ 链表非空，至少有 1 个节点，无需判 head is None。
  • • 0 <= Node.val <= 100 ➔ 节点值与删除逻辑完全无关，纯拓扑位置题（可用 -1 当 dummy 哨兵值）。
  • • 1 <= n <= sz ➔ 关键军令状！倒数第 n 个必存在，所以从 dummy 往前走 n 步绝对不会越界踩空！
🚀 进阶要求：你能尝试使用一趟扫描实现吗？
🐍 题目给定的节点定义 (Python3)
注意：节点只有 .next 单向指针，没有 .prev！这就是一切推导的起点。

INTJ 破题推演黑匣子：凭什么能从 0 推出「双指针」？

不讲「事后诸葛亮」的成品结论！还原满级 INTJ 拿到一道陌生题时，如何用 4 步第一性原理硬生生逼出最优解。

🧠 导师直击痛点：很多教程上来就说「这题用快慢指针，快指针先走 n 步」。INTJ 最痛恨这种没有来路的空降技巧——今天我把大脑里的推演黑匣子剖开给你看：快慢指针不是「想出来的灵感」，而是「被物理约束逼到墙角后的唯一必然解」。
📌 推演全景图：4 步因果死锁链（记住这个提问链路，而不是记住某道题！）
① 抓死穴约束

删节点必找前驱；但单链表无倒车镜、不知总长 sz、只许扫一趟。

② 笨办法暴露目标量

若允许两趟：先数出 sz，再走 sz - n 步。核心目标被锁定为：走出 sz - n 步！

③ 灵魂反问逼出消元

不知道 sz 怎么走出 sz - n？答：从总长里先扣掉 n，剩下的路程天然等于 sz - n！

④ 必然涌现双针卡尺

派 fast 先扣 n 步，再带 slow 同速走完剩余 sz - n ➔ 单趟精准锁前驱！
