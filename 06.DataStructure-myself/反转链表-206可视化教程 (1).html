206. 反转链表 · 状态机模型化教程

先建立系统模型与不变量，再读转移算子，最后用动画做仿真校验。三指针 pre / cur / nxt 把链表切成两个区间，每轮执行同一个原子算子 F，把待处理节点从右区间搬入左区间，直到右区间为空。

难度 Easy 时间 O(n) 最优空间 O(1) 样例 1→2→3→4→5 → 5→4→3→2→1

00核心模型 · 区间、变量与不变量

在看任何动画之前，先固定系统定义。后续每一步推演都只是在维护下面这套定义，不引入新规则。

符号所属区间语义定义（全程不变）
Sᵣ已反转区间内部节点已经按目标顺序反转完成，是一个独立闭环。
Sᵤ待反转区间仍保持原始顺序，尚未处理。
pre指向 Sᵣ 的头已反转区间当前的第一个节点；循环终止时它就是答案。
curSᵤ 的首节点本轮要从 Sᵤ 剥离、并入 Sᵣ 的当前处理节点。
nxtSᵤ 的次节点cur 的后继；用于在改指针前锁住 Sᵤ 的新入口，防止断链丢节点。

边界锚定 · 变量就是区间的交界点

不要把变量当成“临时存值的盒子”；在这个状态机里，每个变量都是贴在区间边界上的锚点。区间收缩 / 扩张，本质就是这些锚点在移动。

变量边界角色交界位置本质
preSᵣ 头部锚点两区间分界线的左侧（Sᵣ 侧）已反转区间的入口
curSᵤ 头部锚点两区间分界线的右侧（Sᵤ 侧）本轮即将被搬运的节点
nxtSᵤ 下一边界备份Sᵤ 的第二个节点改指针前提前抓住的下一个交界点

▶ 核心关系：pre 与 cur 永远相邻，共同构成两个区间的分界线；pre 在左，cur 在右。

INVARIANT · 不变量（每轮结束后必须成立）
  • Sᵣ 内部已完全反转，且 pre 始终是 Sᵣ 的头。
  • Sᵤ 保持原始顺序，未被改动。
  • 两个区间之间没有共享节点；cur 是唯一的搬运节点。
AXIOM · 断链公理（最高优先级约束）
  • 单链表只能向后访问；一旦改写 cur.next，cur 与后继的连接立即断开。
  • 因此必须先把后继存入 nxt，再动 cur.next；顺序不可颠倒。
TERMINATION · 终止条件
  • 当 cur == None，说明 Sᵤ 已空、全部节点并入 Sᵣ；此时 pre 即为反转后链表的头，返回 pre。

01原子转移算子 F · 一轮循环 = 一次状态变换

下面 4 条动作是一个不可拆分的整体：输入旧状态 (pre, cur, nxt)，输出新状态 (pre', cur', nxt')。不要逐行单独理解，把它当成一个函数 F。

F · 单次搬运(pre,cur,nxt) → (pre',cur',nxt')
①nxt = cur.next　备份后继：锁住 Sᵤ 下一个入口。
②cur.next = pre　回指前驱：cur 接到 Sᵣ 头部。
③pre = cur　更新 Sᵣ 头：cur 成为新区间头。
④cur = nxt　游标前移：cur 进入 Sᵤ 原入口。

算子对应的代码（逐行绑定语义阶段）

1def reverseList(self, head):入口
2pre = None初始化 Sᵣ 为空
3cur = head初始化 Sᵤ 起点
4while cur:Sᵤ 非空则继续
5nxt = cur.next阶段① 边界预备
6cur.next = pre阶段② 节点接入
7pre = cur阶段③ 更新 Sᵣ 边界
8cur = nxt阶段③ 更新 Sᵤ 边界

阶段 ①
边界预备
改写 cur 指针之前，先备份 Sᵤ 的下一个入口；否则一旦断链，待反转区间整体丢失。
nxt = cur.next
阶段 ②
节点接入
修改 cur 的 next 指向 pre，把 cur 接到 Sᵣ 头部，正式并入已反转区间。
cur.next = pre
阶段 ③
边界更新
pre 右移一格（Sᵣ 扩大），cur 右移到 nxt（Sᵤ 缩小），分界线整体前进一格。
pre = cur　·　cur = nxt

01.5盲点纠偏 · 把脑海画面落到具体代码

你脑海里的“两个空间此消彼长、方块跳来跳去”是对的；断层出现在：画面是“物体搬运”，而链表代码实际是“改指针 + 挪游标”。这一节把两者逐一对上。

纠偏一：节点没有被搬运，变的只是箭头指向

常见心智幻觉（导致卡住）

以为有一个小方块从 Sᵤ 被复制 / 搬到 Sᵣ，像把积木从右边格子挪到左边格子。

于是会追问：代码里哪一句“把节点搬过去”？找不到这句，就觉得代码和画面对不上。

链表的真实事实

节点对象从头到尾位置不变，内存里没有“搬运”这个动作。唯一被改变的，是节点身上的 next 箭头指向。

所谓“并入 Sᵣ”，等价于把 cur 的箭头掉头指回 pre；所谓“区间移动”，只是 pre / cur 两个游标变量换了指向。

纠偏二：逐行落地 · 每行代码读写了谁、画面变了什么

关键区分：前两行改的是节点身上的箭头（next），后两行改的是游标变量本身（pre / cur）。这是最容易混在一起的地方。

代码行读了谁 / 写了谁区间画面发生什么改动对象
nxt = cur.next 读 cur.next（cur 指向的后继），写入变量 nxt。节点一个都没动。 在动手改 cur 之前，先把 Sᵤ 剩下的第一个节点“抓在手里”备份，防止等下断链后找不到它。 备份游标 nxt
cur.next = pre 改写 cur.next，让它指向 pre。这是本轮唯一修改的节点箭头。 cur 的箭头掉头，从“指向 Sᵤ 后方”改为“指向 Sᵣ 头部”；cur 就此挂到 Sᵣ 贴分界线的头部。 节点箭头 next
pre = cur 把游标 pre 改写为 cur 当前指向的节点。不改任何节点箭头。 Sᵣ 的头锚点右移一格，落到刚接入的 cur 上；Sᵣ 正式扩大一格。 游标变量 pre
cur = nxt 把游标 cur 改写为之前备份的 nxt。不改任何节点箭头。 Sᵤ 的头锚点右移到备份的下一个节点；Sᵤ 缩小一格，准备下一轮。 游标变量 cur

纠偏三：这是一条串行流水线，顺序不可交换

① nxt 备份后继 → ② cur.next 回指 pre → ③ pre 前移 → ④ cur 前移

⚠ 若把 ② 提到 ① 前面：先执行 cur.next = pre，cur 与后继的连接已断开，此时再 nxt = cur.next 拿到的就是 pre，Sᵤ 剩余节点整体丢失。所以 ① 必须先于 ②，这是强时序依赖，不能并行建模。

纠偏四：画面方向与链表方向

  • 两个框左右并排、中间是分界线：Sᵣ 在左，Sᵤ 在右。新节点从分界线一侧进入 Sᵣ，向左堆叠，所以 Sᵣ 从右往左逐渐变宽；Sᵤ 从分界线一侧起，向右缩减。
  • 框内位置 ≠ 链表 next 方向：Sᵣ 框内从左到右是「尾 … 头(pre)」，而链表 next 是从头指向尾，即视觉上箭头朝左；pre 钉在贴分界线的头节点上（Sᵣ 框最右）。
  • 每个方块分两格：左格数据域 val（存数值），右格指针域 next（存下一个节点位置）。代码里 cur.next = pre 改的就是右格；cur.val 才是左格。

02仿真推演 · 用动画校验模型（模型已建立）

此时动画只是模拟器：每点一次「下一步」= 执行一次算子 F。观察两个区间如何此消彼长，确认画面始终满足 00 节的不变量。

pre · Sᵣ 头 cur · 待处理 nxt · Sᵤ 次节点

轮次读法

  • 初始态：Sᵣ 为空（pre=None），Sᵤ = 1→2→3→4→5，cur=1。
  • 每一轮 F：cur 从 Sᵤ 贴分界线的头部剥离，接到 Sᵣ 贴分界线的头部；pre、cur 依次前移。
  • 终止态：Sᵤ 为空（cur=None）；链表 next 顺序为 5→4→3→2→1，pre=5（Sᵣ 框最右的头节点）。

边界 Case

空链表 head=None → 返回 None
单节点 [1] → 一轮后返回原节点
双节点 [1,2] → 2→1

03范式 A · 栈重建法（定位：校验工具，非主模型）

模型：序列化 → 栈后进先出 → 反向重建。先把节点值全部压入数组，再从栈顶弹出逐个新建节点串成新链表。逻辑线性直观，但模型不可迁移、空间 O(n)，仅适合用来核对双指针结果。
def reverseList(self, head):
    if head is None:
        return None
    tmp = []
    cur = head
    while cur:
        tmp.append(cur.val)
        cur = cur.next
    newHead = ListNode(tmp.pop())
    node = newHead
    while tmp:
        node.next = ListNode(tmp.pop())
        node = node.next
    return newHead

状态推演（1→2→3→4→5）

  • 入栈完成：tmp = [1,2,3,4,5]
  • pop(5) → 新头 5，依次弹出拼出 5→4→3→2→1→None
代价：遍历两次链表；空间 O(n)；面试不作最优解推荐。

04范式 C · 递归（定位：同构表达，拓展理解）

子问题定义：reverseList(node) 返回以 node 为起点反转后的头。递归基：node 为空或已是尾节点则直接返回。先递归反转后半段，再把当前节点回指自身、断开原链接。状态藏在调用栈里，不透明，长链表有栈溢出风险。
def reverseList(self, head):
    if head is None or head.next is None:
        return head
    newHead = self.reverseList(head.next)
    head.next.next = head
    head.next = None
    return newHead

06链表题通用避坑清单

✕ 把类名 ListNode 作为循环 / 赋值变量
✓ 类型名只读不可写；状态游标用 cur / pre / nxt。
✕ 改 cur.next 前不缓存 nxt，直接断链丢节点
✓ 遵守断链公理：先 nxt = cur.next，再改指针。
✕ 遗漏空链表、单节点等边界
✓ 先跑 head=None、单节点、双节点三类用例。
✕ 反转结束 return cur
✓ 终止时 cur 必为 None；新头是 pre，return pre。
